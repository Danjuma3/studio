# Kitchen Prof

Kitchen Prof is an intelligent food cost control and margin analysis platform designed specifically for the volatile restaurant market in Lagos, Nigeria.

## Core Interfaces

1.  **Stock Taking**: Real-time pantry monitoring with low-stock alerts.
2.  **Cost Percentage**: Instant food cost % analysis to protect margins.
3.  **Auto Profit Calculator**: AI-driven performance audits and procurement strategies.

## Key Features

- **Market Sync**: Updates based on Lagos Island and Mile 12 market trends.
- **Recipe Composer**: Precise plate costing by combining ingredients.
- **Manager Tools**: Oversight of kitchen staff and daily checklists.
- **AI Insights**: Automated suggestions for bulk vs. retail procurement.

## Built With

- Next.js (App Router)
- Tailwind CSS
- ShadCN UI
- Genkit (AI Analysis)
- Firebase (Storage & Logic)
